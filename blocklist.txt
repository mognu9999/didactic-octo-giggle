# Свой список запрещённых слов и фраз.
#
# Всё, что вы впишете сюда, бот будет удалять у всех в беседе. Файл можно
# править прямо на GitHub (карандаш -> Commit changes) — Railway перезапустит
# бота сам.
#
# Правила:
#   * одна строка — одно слово или фраза; строки с # и пустые игнорируются
#   * регистр не важен, "ё" = "е"
#   * слово ловится с начала и с любым окончанием: "реклам" поймает "реклама",
#     "рекламу", "рекламный"
#   * знак $ в конце строки значит "слово целиком": "бот$" поймает "бот", но не "ботан"
#   * пробел в фразе заменяет любое количество пробелов: "продам аккаунт"
#
# Сюда стоит добавлять то, что зависит от контекста и меняющихся списков и
# поэтому не зашито в бота: например, названия запрещённых организаций,
# ваши стоп-слова для спама и рекламы, и т.п. Решать, что именно запрещено
# в вашей беседе, должны вы — бот лишь исполняет список.
#
# Примеры (уберите # в начале, чтобы включить):
# продам аккаунт
# заработок без вложений
# подпишись на канал
